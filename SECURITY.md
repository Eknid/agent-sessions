# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue containing credentials, session logs, private prompts or exploit details.

Include the affected version, reproduction steps and the expected impact. You should receive an acknowledgement within seven days.

## Sensitive data

Agent session logs can contain prompts, model responses, file paths and tool output. Remove sensitive information before attaching diagnostics to an issue.
